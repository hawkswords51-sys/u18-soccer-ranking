チームページを公開します。対象: $ARGUMENTS （指定が無ければ変更されている team-profiles すべて）

次の順番で進めてください。途中で異常があれば止めてKeiに報告すること。

1. `git --no-optional-locks status` と `git diff` で今回の変更内容を確認する。
   data/team-profiles/ 以外のファイルが変更されていたら、**先にKeiに報告して指示を待つ**。

2. 変更された md を読み、CLAUDE.md の「チームページの公開前チェック」を全項目実施する。

3. リポジトリを /tmp にコピーし、**コピーの方で** ページ生成スクリプトを実行して、
   エラーなく完走するか・生成HTMLの h1 が1つか・情報カードが欠けていないかを確認する。
   （リポジトリ内では絶対に実行しない）

4. 問題なければ、変更した md ファイルだけを個別に git add し、
   何をコミットするかの一覧をKeiに見せて承認を取る。

5. 承認が出たら Commit → Push する。コミットメッセージは日本語で簡潔に
   （例: 大社高校ページ: 創部年1935を追加）。

6. Push後、`git log origin/main -1` でリモートに届いたことを確認する。
   その後2〜3分待って、公開ページを `?nocache=今日の日付` 付きで取得し、
   直した箇所が実際に反映されているか確認して報告する。
